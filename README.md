# CardHub · 名片记录系统

一款 Windows 桌面名片管理工具：拍照导入名片 → 自动裁剪校正 → 文字识别 → AI 补全公司与工商信息 → 建立可检索、可统计的名片库。

- **下载安装**：到 [Releases 页面](https://github.com/TookuW/NamecardHub-Release/releases) 下载最新的 `CardHub-Setup-*.exe`
- **数据私有**：所有名片数据保存在你自己的电脑上，不上传任何服务器

---

## 一、快速上手

### 1. 安装

1. 打开 [Releases 页面](https://github.com/TookuW/NamecardHub-Release/releases)，下载最新版本的 `CardHub-Setup-x.y.z.exe`
2. 双击运行。**首次安装 Windows 可能弹出蓝色警告「Windows 已保护你的电脑」**——本应用暂未购买代码签名证书，属正常现象：点击「更多信息」→「仍要运行」即可继续
3. 按提示选择安装目录（默认即可，无需管理员权限），完成安装后桌面出现 CardHub 图标

### 2. 首次启动

1. 双击打开 CardHub，等待几秒（应用在后台启动本地识别引擎）
2. 首次启动会自动弹出「设置」窗口，顶部提示**填入你的大模型 API Key**——这是 AI 分析功能的凭据：
   - 支持 OpenAI 兼容协议的服务（智谱 GLM、DeepSeek、通义等，默认预填智谱地址）或 Anthropic 协议
   - 在对应平台注册后创建 API Key，粘贴进输入框，点「测试连接」确认显示绿色「连通正常」
   - 保存后即可使用全部功能；**不填也能用**——自动裁剪和文字识别不受影响，只是没有 AI 分析
3. 弹窗只会出现一次，之后可随时通过右上角「设置」修改

### 3. 导入第一张名片

点击顶栏「**导入名片**」，两种方式任选：

- **从电脑选择照片**：挑选拍好的名片照片（支持一张照片里有多张名片，会自动拆分）
- **扫描待导入文件夹**：把照片批量放进安装目录下的 `Input` 文件夹（如
  `%LOCALAPPDATA%\Programs\CardHub\Input`），然后在应用里点「扫描待导入」即可全部导入。
  也可以在应用的「导入名片 → 打开待导入文件夹」里一键直达该文件夹。
  若安装目录没有写权限（少见），文件夹会自动改放到 `%APPDATA%\CardHub\Input`。

导入后应用自动处理：识别卡片边界 → 透视校正 → 文字识别（OCR）→ 结构化成「姓名 / 职位 / 公司 / 电话 / 邮箱 / 地址」等字段。处理完成的卡片会出现在名片库里。

## 二、流程运作

CardHub 的处理分两个阶段，全部在本机完成：

### 阶段一：算法处理（自动、免费、离线）

| 步骤 | 说明 |
|---|---|
| 多卡拆分 | 一张照片含多张名片时，自动检测并逐张拆开 |
| 四边校正 | 检测卡片四个角，把倾斜拍摄的卡片拉正成标准矩形 |
| 文字识别 | 本地 OCR 引擎识别卡片上的所有文字 |
| 规则抽取 | 从识别文本中按规则抽出电话、邮箱、网址等格式固定的字段 |

### 阶段二：AI 分析（需要 API Key，按卡片勾选执行）

对识别完的名片，可以让大模型做深度加工：

- **字段复核**：结合名片原图纠正 OCR 错字、补漏字段
- **公司档案**：联网检索公司资料，生成一句话简介与业务要点
- **工商核验**：从国家企业信用信息公示系统等公开来源补全统一社会信用代码、法定代表人、注册资本、参保人数等
- **产业链定位**：判断公司所处行业、产业链上下游环节、规模分级

操作方式：打开一张名片 → 点右上角「✦ 交给大模型分析」；或在列表里勾选多张后批量处理。

### 日常管理

- **搜索**：顶栏搜索框支持姓名、公司、职位、电话、邮箱等全文检索（快捷键 `/`）
- **筛选**：左侧栏按行业、产业链环节、公司规模、职位分类等维度过滤
- **编辑**：名片详情里所有字段可直接点击修改，光标移开自动保存
- **手动校正**：如果自动裁剪框歪了，详情页点「调整四点边界」，在**原始照片**上手动拖动四个角，确认后自动重跑识别（按住 `Alt` 拖动可暂时关闭边线吸附）
- **跟进记录**：每张名片可记录跟进阶段（初识 → 已联系 → 意向 → 报价 → 成交/流失），带提醒功能
- **统计看板**：顶栏切换到「统计看板」，查看导入趋势、行业分布、置信度分布等图表

### 数据存放在哪里？

所有数据保存在本机用户目录 `%APPDATA%\CardHub`（资源管理器地址栏粘贴即可打开）：

```
%APPDATA%\CardHub\
├── data\cards.db      名片数据库（SQLite）
├── data\original\     导入的原图副本
├── Input\             待导入文件夹（可把照片放这里批量导入）
└── Output\            识别结果导出（每张名片一个 JSON）
```

卸载应用不会删除这个目录；换电脑时把整个目录拷到新机器相同位置即可迁移全部数据。

## 三、更新方式

### 自动更新（推荐，无需操作）

1. 每次打开 CardHub 后约 5 秒，应用在后台静默检查新版本
2. 发现新版本时自动下载（不占用前台、不打断使用）
3. 下载完成后弹出提示：「新版本 x.y.z 已下载完成」——可点「立即重启并更新」，或选「稍后再说」
4. 选了「稍后」也没关系：**下次启动时自动应用新版本**

你的名片数据、API Key、所有设置在更新过程中原样保留，不受影响。

### 手动更新

如果自动更新因网络问题长时间未完成，也可以随时回到本仓库的 [Releases 页面](https://github.com/TookuW/NamecardHub-Release/releases)，下载新版安装包直接覆盖安装，数据同样不会丢失。

> 提示：本仓库发布在 GitHub，国内网络下载速度可能波动。若安装包下载缓慢，换个时间段重试通常即可。

## 四、技术简介

供技术背景的读者了解 CardHub 的工作方式（使用本应用无需了解以下内容）。

### 架构

```
┌─────────────────────────────────────────────┐
│  Electron 壳（桌面窗口、自动更新、进程管理）    │
│    └─ 加载 http://127.0.0.1:8733            │
├─────────────────────────────────────────────┤
│  cardhub-backend.exe（PyInstaller 打包）      │
│    FastAPI + uvicorn，监听本机回环地址         │
│    ├─ CV 管线：OpenCV / DocAligner / YOLO    │
│    ├─ OCR：RapidOCR（PP-OCR 系列 ONNX 权重）  │
│    ├─ 检索层：多引擎 SERP + 国信公示抓取       │
│    └─ SQLite 数据库（cards.db）              │
└─────────────────────────────────────────────┘
```

- **本地优先**：图像处理、OCR、数据库全部离线运行；唯一的外网请求是「AI 分析」阶段的联网检索与模型 API 调用
- **进程模型**：Electron 主进程负责拉起/关闭后端进程、选择空闲端口、单实例锁；窗口关闭即回收后端进程
- **数据隔离**：程序安装目录只读，运行时数据一律写入用户目录（`%APPDATA%\CardHub`），更新覆盖程序文件不影响数据
- **自动更新**：基于 electron-updater + GitHub Releases；启动后台拉取 `latest.yml` 比对版本，差量下载（blockmap），下次启动应用
- **AI 分析**：支持 OpenAI 兼容与 Anthropic 双协议；模型可配置联网检索工具，检索层内置国家企业信用信息公示系统（gsxt.gov.cn）导向查询与多引擎 SERP 解析

### 隐私说明

- 名片照片与识别结果只存在于你的电脑，应用不做任何上传
- AI 分析时，仅当卡片的文字内容与公司名会发给你配置的模型服务商；检索请求发往公开搜索引擎
- 自动更新仅与本仓库（GitHub Releases）通信，不收集任何遥测数据
